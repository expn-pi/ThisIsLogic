# Assembly design

- The GameMode (`AThisIsLogicGameMode`) assembles the table, as a Composition Root: it creates the pieces, decides where they go and connects their events, and does nothing after that. Unreal's GameMode already sets the game's rules and default classes (such as the camera pawn), so assembling the table extends its role with no new class. Every other class stays independent: it receives what it needs and never looks for it. The exercise is still an exception, since it reads the levels' table from `UThisIsLogicSettings` itself (see Pending in `CLAUDE.md`).
- In its `BeginPlay`, in this order, it creates: the formula, at the table's origin, with the rows' maximum width; the background target, below the table, whose tap goes straight to the formula's `ClearSelection`; the exercise, spawned deferred and given the formula through `SetFormula`; the panel, connected to the formula and the exercise; then it calls the exercise's `FinishSpawning`, which runs its `BeginPlay`; and last the operator palette, whose two insert events go straight to the formula's `InsertBlock` and `InsertBlockAfter`.
- The exercise is spawned deferred so that it already has its formula when its `BeginPlay` runs (setter injection, since actors take no constructor parameters), and so that the panel can be connected in between: the panel needs the exercise for Restart and Undo, and the exercise, as it starts, empties and fills the formula, which sends the selection event the panel listens to.
- Each event is bound straight to the class that does the work: the panel's Minimize all, Maximize all, Minimize/Maximize and Remove go to the formula, Restart and Undo to the exercise, the background's tap to the formula, the operator palette's insert events to the formula, and the formula's selection event to the panel. The formula's change event goes to the exercise, which binds it itself, since it saves the snapshots for Undo. No class relays an event it does nothing with.
- The formula's selection event carries two values: whether a block is selected and whether it is a proposition. The panel shows or hides its buttons from them and needs no reference to the formula; such a reference would also close an include cycle, since `Formula.h` includes `Block.h`, which includes `ThisIsLogicSettings.h`, which includes `CommandPanel.h`.
- The selection event sends one notification per change, once the state is final (`SelectBlock` unmarks the previous block through `DeselectBlock`, which does not notify). It may also come when nothing changed (tapping the selected block, or the background with nothing selected), which is harmless, since the panel only shows what it receives.
- Positions and areas on the table (the formula's place and its rows' width, the operator palette's place, the background's depth) belong to the GameMode, since they describe the table as a whole; each piece decides only its own inner sizes, such as its blocks' height (see `Docs/Scale.md`).
- Rejected: the exercise creating the formula, the background and the panel (it would decide positions, and the palettes, which need the formula, would have to get it from the exercise or be known by it, making it the center of everything again); a level manager that controls the exercise and passes it the palettes' decisions (a center that keeps acting after the setup); hand-made singletons holding the pieces (the garbage collector does not see them, and Play in Editor may run several worlds at once); subsystems used to look the pieces up (a Service Locator: each class hides what it depends on, while the GameMode shows every connection in one place); the panel asking the formula for the selection (the include cycle above, and a UI class depending on a gameplay class); the selection event carrying the selected block (its listener would keep a copy of the selection); `SelectBlock` calling a notifying `ClearSelection` (switching blocks would send two notifications, the first with nothing selected); the exercise placed in the `Main` map (it needs its formula before its `BeginPlay`, which only the GameMode, creating both, can give).
