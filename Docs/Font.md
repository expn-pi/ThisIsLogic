# Font design

- The text of the blocks and the indicators is drawn by `UTextRenderComponent`, which takes only offline fonts: a texture with the characters drawn in advance at a fixed size, plus a table of where each one is (`Characters`). An offline font cannot fall back to another font for a missing character, as UMG's runtime fonts can, so one font must hold every character they show: the letters of the sentences, the textbook symbols and the indicators' symbols.
- The font is DejaVu Sans Condensed Bold 2.37, the condensed bold weight of DejaVu Sans: its characters are 10% narrower than those of DejaVu Sans Bold, the weight the table's look picked (see `Docs/Visuals.md`), so maximized propositions take less room. It has all the operators' symbols (⊤ ⊥ ¬ ∧ ∨ ⊕ ↑ ↓ → ← ↔), the indicators' (✔ ✗ ≡ ≢ ∅) and the Latin letters, and its free license allows shipping it in a public repository. The TTF and its license are in `Data/Fonts/DejaVuSans/`, as the source and record of the asset, like `Levels.csv` for `DT_Levels`.
- The asset is `Font_DejaVuSans`, in `Content/Gameplay/Block/`, with Font Cache Type set to Offline; it kept its name when it moved to the condensed weight, so no path changed. The editor generates an offline font from a font installed in Windows, chosen by its name and the bold option, not from the TTF file, so DejaVu Sans Condensed Bold 2.37 must be installed to regenerate it.
- Its Import Options: Font Name DejaVu Sans Condensed; Height 48, the size at which each character is drawn in the texture; Enable Bold on, which takes the installed bold weight; Use Distance Field Alpha on; and Chars listing every character the blocks and the indicators may show: the printable ASCII characters, the space among them, and the symbols. Everything else keeps its default.
- The distance field is needed because the text materials expect one, the engine's default and `M_Text` alike, as does the default font, RobotoDistanceField: without it, each character showed as a full rectangle. In the texture preview, a distance field font looks blurred, as expected, and so does the preview of a material that samples it.
- Chars imports only the characters listed in it: Include ASCII Range applies to Unicode Range, not to Chars. Before the ASCII characters were listed, the letters were missing, the text measured zero width, and every block became a circle. A sentence with a character outside the list (an accented letter, say) needs it added; the levels are in English, so ASCII is enough for now. The space goes in the middle of the field, since one at either end may be dropped.
- To regenerate after changing an option, such as Font Name or Chars: save the asset, then Reimport it from the Content Browser, which takes the font from the Import Options. The Windows font dialog opens when Font Cache Type is set to Offline, as the asset is made. Update All in the Font Editor does not regenerate the font: it asks for texture files, to bring back pages edited outside the engine, as the pair of Export All.
- The editor's own font lacks ⊤, so the Chars field shows it as a square. To check that a character was imported, look at the texture preview or compare the count of `Characters`.
- The text material is `M_Text`, in `Content/Gameplay/Block/`, which the GameMode reads from `UThisIsLogicSettings` for the indicators (see `Docs/Indicators.md`). It is unlit, so it needs no light: the engine's default text material, `DefaultTextMaterialOpaque`, reacts to light, and on the table, which has none, it drew the indicators' white labels black. Its Blend Mode is Masked, its Shading Model Unlit and its Opacity Mask Clip Value 0.5, the distance field's value at the edge of a character. Its graph has two nodes: Vertex Color, whose RGB goes to Emissive Color, since `UTextRenderComponent` passes its color (`TextRenderColor`) to the material as the vertices' color; and a Font Sample Parameter with `Font_DejaVuSans`, page 0, whose alpha, the distance field, goes to Opacity Mask. `UTextRenderComponent` sets its material's font parameters to its own font, which is how the default material draws DejaVu's symbols on the blocks, so the font in the node only serves to compile the material and for its preview. The blocks' labels still use the default material (see Pending in `CLAUDE.md`).
- Rejected: a runtime font with a second font for the symbols (`UTextRenderComponent` takes only offline fonts, which have no fallback); RobotoDistanceField, the default (it lacks the symbols); a font without distance field (full rectangles); Unicode Range for the symbols (a forum report says a range of arrows froze the 5.2 editor, and here, with Chars filled in, a range of `22A4`, the ⊤, added nothing); Impact and Arial Rounded (Microsoft's font FAQ forbids turning Windows fonts into bitmap fonts for games, which an offline font is, and both are licensed through Monotype; nothing on Microsoft's pages for them shows the logic symbols either); DejaVu Sans Bold, the first weight of the table's look (10% wider than the condensed weight, so maximized propositions took more room); keeping other TTFs of the family in `Data/Fonts/` (only the condensed bold weight is used); the engine's default text material for the indicators (it reacts to light, so their white labels came out black on the table, which has no light); a light on the table, so that the default material would show them white (it did, but it changed the table's look); `M_Block` for the text (it reads no font, so each character would be a full rectangle, and it ignores the vertices' color that carries `TextRenderColor`; teaching it both, with a Static Switch and an instance for text, would give one graph two jobs).
