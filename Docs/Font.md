# Font design

- The blocks' text is drawn by `UTextRenderComponent`, which takes only offline fonts: a texture with the characters drawn in advance at a fixed size, plus a table of where each one is (`Characters`). An offline font cannot fall back to another font for a missing character, as UMG's runtime fonts can, so one font must hold every character the blocks show: the letters of the sentences and the textbook symbols.
- The font is DejaVu Sans 2.37: it has all the symbols (⊤ ⊥ ¬ ∧ ∨ ⊕ ↑ ↓ → ← ↔) and the Latin letters, and its free license allows shipping it in a public repository. The TTF and its license are in `Data/Fonts/DejaVuSans/`, as the source and record of the asset, like `Levels.csv` for `DT_Levels`.
- The asset is `Font_DejaVuSans`, in `Content/Gameplay/Block/`, with Font Cache Type set to Offline. The editor generates an offline font from a font installed in Windows, chosen by name, not from the TTF file, so DejaVu Sans 2.37 must be installed to regenerate it.
- Its Import Options: Height 48, the size at which each character is drawn in the texture; Use Distance Field Alpha on; and Chars listing every character the blocks may show: the printable ASCII characters, the space among them, and the symbols. Everything else keeps its default.
- The distance field is needed because the default material of `UTextRenderComponent` expects one, like its default font, RobotoDistanceField: without it, each character showed as a full rectangle. In the texture preview, a distance field font looks blurred, as expected.
- Chars imports only the characters listed in it: Include ASCII Range applies to Unicode Range, not to Chars. Before the ASCII characters were listed, the letters were missing, the text measured zero width, and every block became a circle. A sentence with a character outside the list (an accented letter, say) needs it added; the levels are in English, so ASCII is enough for now. The space goes in the middle of the field, since one at either end may be dropped.
- To regenerate after changing an option: save the asset, then Reimport it from the Content Browser. Update All in the Font Editor does not regenerate the font: it asks for texture files, to bring back pages edited outside the engine, as the pair of Export All.
- The editor's own font lacks ⊤, so the Chars field shows it as a square. To check that a character was imported, look at the texture preview or compare the count of `Characters`.
- Rejected: a runtime font with a second font for the symbols (`UTextRenderComponent` takes only offline fonts, which have no fallback); RobotoDistanceField, the default (it lacks the symbols); a font without distance field (full rectangles); Unicode Range for the symbols (a forum report says a range of arrows froze the 5.2 editor, and here, with Chars filled in, a range of `22A4`, the ⊤, added nothing).
